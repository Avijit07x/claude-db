Install the package once, then switch it on for a project.

## Requirements

- Node 22.16 or newer (`node -v`)
- A git repository
- Claude Code, logged in

Nothing compiles at install time. SQLite comes from Node itself.

## Install

```bash
npm install -g claude-db
```

Every command also works as `cdb`.

## Switch it on

<Steps>
<Step n={1} title="Run install inside the project">

```bash
cd your-project
claude-db install --project
```

`--project` limits it to this repository. Run `claude-db install` without it to switch it on for every project on this machine. The folder you run it from does not matter in that case.

</Step>
<Step n={2} title="Restart Claude Code">

Hooks and the MCP server load only when Claude Code starts. A session that is already open does not have them.

</Step>
</Steps>

Add `.mcp.json` and `CLAUDE.local.md` to your `.gitignore`. They hold paths and rules that are personal to your machine.

## What install adds

| Where                         | What it is                                                        |
| ----------------------------- | ----------------------------------------------------------------- |
| `.claude/settings.local.json` | The hooks that capture and recall                                 |
| `.mcp.json`                   | The server that gives Claude the six [MCP tools](/docs/mcp-tools) |
| `CLAUDE.local.md`             | A standing instruction to search memory before asking you         |
| `.claude/skills/`             | The [skills](/docs/skills): `/cdb-scan`, `/catchup`, `/handoff`   |

A machine-wide install writes the same things under `~/.claude/` and `~/.claude.json` instead. Memory is always one database for the whole machine, filed by project.

## Check it works

```bash
claude-db doctor
claude-db status
```

`doctor` should show `wiring : ok` and list the three skills. `status` fills in after your first real session. Nothing is saved for a chat that only asked questions, and that is normal.

For a full test, run `claude-db doctor --deep`. It writes one test memory, finds it, reads it back and deletes it.

## Upgrade

```bash
npm install -g claude-db
```

Restart Claude Code. Your memory is kept.

## Uninstall

```bash
claude-db uninstall --project
```

This removes the hooks, the MCP entry, the instructions and the skills. Your memory is left on disk, so reinstalling picks up where you stopped. To delete the memory itself, see [Privacy](/docs/privacy).
