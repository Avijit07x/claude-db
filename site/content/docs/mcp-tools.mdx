Install gives Claude six tools. You do not call them yourself. Claude uses them when a question needs more than the memory already shown above your prompt.

| Tool               | What it does                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------ |
| `search`           | Searches this project's memory. Returns a short index: id, kind, date, title and one line. |
| `get_observations` | Gives the full text for ids from `search`, up to 25 at once.                               |
| `timeline`         | Shows what happened recently, in order. Answers "what was I working on?".                  |
| `find_usages`      | Queries the [code graph](/docs/code-graph) in four modes.                                  |
| `remember`         | Saves a rule you state outright, such as "always use pnpm here".                           |
| `forget`           | Deletes memory by id when it turned out to be wrong.                                       |

## How memory is read

Memory is read in two steps, so a broad question does not pull full text into the chat. `search` returns the short index, and Claude then asks `get_observations` for only the ids worth reading.

`search` can filter by `kind` (`decision`, `pattern`, `bugfix`, `context`, `deadend`, `preference`), by `tag`, and by `project`. Pass `"*"` as the project to search every project.

## Symbols

For a code symbol, `find_usages` beats grep: it marks the likely definition and answers from the current source every time. Plain grep still wins for logs, comments, strings and prose.
