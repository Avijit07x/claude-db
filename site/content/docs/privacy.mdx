Memory lives in a database you choose. There is no account and no telemetry.

## What uses the network

Embeddings and parsing run on your machine. Four things can reach the network, and each has an off switch.

- **Your database**, only if you set a remote one with `claude-db use`.
- **Turning chats into facts.** After a chat ends, its saved, redacted text is sent once to Claude Haiku through your own Claude Code login. At most 30 calls a day. `claude-db distill off` stops it.
- **Picking memory for a prompt.** The prompt, the end of Claude's last reply and up to ten saved excerpts go to Haiku through the same login. At most 150 calls a day. `claude-db pick off` stops it.
- **The update check.** Once a day, the npm registry is asked for the latest version. Set `"updates": "off"` to stop it.

## What is never stored

- `.env` files and anything under `secrets/`
- `node_modules` and `.git/`
- Anything inside `<private>...</private>`, which is removed before the turn is saved

API keys and tokens are redacted before anything is saved or sent. The raw transcript stays where Claude Code put it. claude-db keeps a short note per turn: a title, the reasoning and the files touched.

## Deleting memory

```bash
claude-db forget <id>
claude-db prune --older-than 90 --yes
claude-db reset --project --yes
```

`prune` and `reset` are dry runs without `--yes`. Uninstalling does not delete memory. These commands are the only thing that does.
