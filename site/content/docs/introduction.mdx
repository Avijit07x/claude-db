claude-db gives Claude Code a memory that lasts and a map of your code. It runs on your machine, against your own database.

## Why

Every Claude Code chat starts from zero. You explain the same decisions, dead ends and rules again, and Claude works out what calls what from scratch.

claude-db keeps what you decided and a map of your code, and gives Claude the right part of it at the right time.

## Get started

You need Node 22.16 or newer and a git repository.

```bash
npm install -g claude-db
cd your-project
claude-db install --project
```

Restart Claude Code. There is nothing else to run. Continue with [Installation](/docs/installation) and the [Quick start](/docs/quick-start).

## What it is not

It is not a cloud service, and there is no account or telemetry. Memory lives in a database you choose. Two small features call Claude Haiku through your own Claude Code login, and each has an off switch. See [Privacy](/docs/privacy).

It does not replace `CLAUDE.md`. A stable overview of your project belongs there. claude-db stores what actually happened.
