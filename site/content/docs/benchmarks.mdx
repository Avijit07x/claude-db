Recall is not free: it costs tokens whenever it fires. These are measured numbers, including the
cases where it does not pay off. Lookups are measured on this repository; recall is priced by
replaying 300 real prompts from a project with about 660 memories.

## The standing cost

Recall costs about 20 tokens a prompt on average, and nothing at all on 69% of prompts, where no
earlier chat fits well enough.

## The refund

Asking who defines and calls `closeObservations` by hand means a grep, then opening three store
adapters to work out which hits are definitions. One `explain` call answers it already classified:
**2.0x cheaper**, measured across eight real symbols in this repo.

```text
  every prompt costs       20 tokens of recall
  every lookup refunds    685 tokens   (1,338 by hand - 653 with)

  so one lookup pays for 33.9 prompts of recall
```

## Where it loses

A symbol with two or three references is cheaper to grep than to look up, because the graph answer
carries structure the question did not need. The full write-up lists every symbol measured, including
those.

</Callout>

## Run it yourself

```bash
git clone https://github.com/Avijit07x/claude-db
cd claude-db && npm install && npm run build

npm run bench:ab      # with and without, per symbol
npm run bench:tokens  # what recall costs per prompt
```

Both run against whatever repository you point them at, so the interesting number is the one from
your own codebase rather than from this one.
