Recall costs tokens whenever it fires, and a code lookup saves tokens when it replaces a grep. These are the measured numbers, including where it does not pay off.

## Recall cost

Recall costs about 20 tokens a prompt on average, and nothing on 69% of prompts, where no earlier chat fits well enough. Measured by replaying 300 real prompts from a project with about 660 memories.

## Code lookup

Asking who defines and calls `closeObservations` by hand means a grep, then opening three store adapters to tell definitions from calls. One `explain` call answers it already sorted.

```text
by hand       1,338 tokens
with graph      653 tokens
saved           685 tokens   (2.0x cheaper, eight real symbols)
```

One lookup saves as many tokens as recall costs over about 34 prompts.

## Where it loses

A symbol with two or three references is cheaper to grep, because the graph answer carries structure the question did not need. [With and without](https://github.com/Avijit07x/claude-db/blob/main/docs/with-and-without.md) lists every symbol measured, losses included.

## Run it yourself

```bash
git clone https://github.com/Avijit07x/claude-db
cd claude-db && npm install && npm run build
npm run bench:ab
npm run bench:tokens
```

Both run against any repository you point them at, so the number that matters is the one from your own code.
